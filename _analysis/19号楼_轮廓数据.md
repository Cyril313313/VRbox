## 4. 左上圆角的证据链（2026-10-14 新增）

用户指出「左上角应该是有弧度的不是直角」。像素级复核结论：

| 证据 | 数值 | 结论 |
|---|---|---|
| 平面图上最外缘青线沿行/列的外沿函数 | 从 (481,565) 平滑过渡到 (642,402)，无尖角 | 是圆弧不是直角 |
| 图中标注文字（6× 放大识读） | **R1800** | 半径标注 |
| 标注引线端点 | 断成 3 段：(368,341)→(497,446)→(529,472)，末端 **(529,472)** | 落在**内皮弧**上（同高度外皮弧在 x=512） |
| 红色轴网交点 | x=642（19-1 轴东 1 800）× y=563（19-E 轴） | 圆心 |
| 圆心到外皮 x=481 / y=402 | 161 px / 161 px | 外皮 **R2 000**（= 1 800 + 墙厚 200）|
| 圆心到内皮 x=498 / y=418 | 144 px / 144 px | 内皮 **R1 800** ✓ 与标注完全一致 |
| 90° 角标（绿色角度标注弧，圆心同交点，R≈383 px） | 顶边与左边夹角 = 90° | 圆角为 90° 转角弧 |
| 墙厚（青线双线间距） | 17 px / 16 px ≈ **200 mm** | 与上表 1 800 → 2 000 的差值吻合 |
| 总平面图同一角点（像素 198,170） | 也是圆角，外皮切长 ≈ 54.5 px = **1.68 m** | 小比例总图简化，取详图口径 |
